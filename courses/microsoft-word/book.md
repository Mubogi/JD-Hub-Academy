# Module 1 — Why Most People Use Word Badly

Almost everyone can type in Word. Almost nobody can make a document that behaves.
The difference shows up the moment the document gets long: numbering breaks,
headings drift, the table of contents goes stale, and the whole thing has to be
rebuilt by hand.

The cause is always the same: manual formatting instead of styles. This course
fixes that in the first two modules, and everything after it becomes easy.

::: scripture
"Let all things be done decently and in order."
— 1 Corinthians 14:40
:::

A document that is in order takes less time to produce and is trusted more by
whoever reads it. Presentation is not vanity; it is a signal about the care behind
the content.

## Lesson 1.1 — The interface, in five minutes

**The ribbon** — the toolbar across the top, grouped into tabs.
**The document area** — where you type.
**The status bar** — word count, page number, zoom.
**The navigation pane** — the outline of your document. Turn it on; it changes how
you work.
**The quick access toolbar** — save, undo, redo. Learn the shortcuts.

## Lesson 1.2 — The ten shortcuts that halve your time

| Shortcut | Action |
|---|---|
| Ctrl+S | Save (do it constantly) |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+C / Ctrl+V / Ctrl+X | Copy / paste / cut |
| Ctrl+F | Find |
| Ctrl+H | Find and replace |
| Ctrl+B / Ctrl+I / Ctrl+U | Bold / italic / underline |
| Ctrl+Enter | Page break |
| Ctrl+Shift+C / Ctrl+Shift+V | Copy / paste formatting |
| Ctrl+A | Select all |
| F7 | Spell check |

Ctrl+H is the most under-used. Replacing every occurrence of a wrong name in a
40-page document takes four seconds.

## Lesson 1.3 — The document you will build

By the end of this course you will have produced: a professional letter, a CV, a
report with a table of contents, a mail-merged certificate set, and a print-ready
policy document. Keep all of them.

::: exercise
**Exercise 1.3 — Shortcut drill**

1. Type a paragraph of at least 100 words.
2. Use Ctrl+H to replace one word with another throughout.
3. Use Ctrl+F to find a specific phrase.
4. Use Ctrl+Enter to add a page break.
5. Save. Then save again.

**Time:** 20 minutes. **Deliverable:** a paragraph and a habit.
:::

# Module 2 — Styles: The Thing That Changes Everything

## Lesson 2.1 — What a style is

A style is a saved set of formatting. Instead of making text bold and size 18
every time, you apply the "Heading 1" style, which already contains those settings.

Three consequences, all large:

1. Change the style once, and every heading in the document updates.
2. The navigation pane shows your document structure.
3. A table of contents can be generated automatically.

## Lesson 2.2 — The five styles you need

| Style | Use |
|---|---|
| **Title** | The document title, once |
| **Heading 1** | Major sections |
| **Heading 2** | Sub-sections |
| **Normal** | Body text |
| **Caption** | Figure and table captions |

Use only these five and your document will look professional. Use more and you
will spend your life maintaining them.

## Lesson 2.3 — Modifying a style

Right-click the style in the gallery, choose Modify, and set: font, size, colour,
spacing before and after, line spacing.

Set spacing *in the style*, not by pressing Enter twice. Pressing Enter twice is
the single most common cause of documents that fall apart.

## Lesson 2.4 — Why this saves hours

A 40-page report with 60 headings: manually formatted, changing the heading colour
takes 60 operations. With styles, it takes one.

::: exercise
**Exercise 2.4 — Style a document**

1. Type a two-page document with at least five headings.
2. Apply Heading 1 to the main sections, Heading 2 to the subsections.
3. Modify Heading 1 to be a colour of your choice.
4. Watch every heading change at once.
5. Open the navigation pane and click through the headings.

**Time:** 30 minutes. **Deliverable:** a styled document with a working outline.
:::

# Module 3 — Layout, Sections and Page Control

## Lesson 3.1 — Margins and page setup

Set margins once, in Layout. Standard professional margins are 2.5 cm all round.
Narrower margins look cramped and are harder to print.

Set the paper size to A4 for Uganda and most of the world. US Letter is different
and will shift every page break.

## Lesson 3.2 — Sections

A section break lets different parts of the document have different settings —
different orientation, different headers, different numbering.

Use case: a report with portrait text and one landscape table. Insert a section
break before the table, change its orientation, insert another break after.

## Lesson 3.3 — Headers, footers and page numbers

Insert → Header, Footer, Page Number. Then the crucial step: "Different First
Page" so the cover has no page number, and "Link to Previous" turned off where you
want numbering to restart.

## Lesson 3.4 — Columns and text boxes

Columns for newsletters and reports. Text boxes for callouts and pull quotes.
Both are underused and both make a document look designed rather than typed.

::: exercise
**Exercise 3.4 — Build a mixed layout**

1. Create a three-page document.
2. Make page one a cover with no header or page number.
3. Add a header with the document title on pages two and three.
4. Insert a landscape section with a wide table.
5. Add page numbers starting from page two.

**Time:** 40 minutes. **Deliverable:** a document with mixed orientation and
correct numbering.
:::

# Module 4 — Tables and Images

## Lesson 4.1 — Tables that behave

Insert → Table, then use the Table Design and Layout tabs.

Key skills: merging cells, adjusting column widths by dragging the border (not by
adding spaces), repeating header rows across pages, and preventing rows from
splitting across pages.

That last one — "Allow row to break across pages" turned off — fixes the single
most annoying table problem in long documents.

## Lesson 4.2 — Images without chaos

Insert the image, then set its **layout options**:

| Option | Behaviour | Use for |
|---|---|---|
| In Line with Text | Behaves like a character | Most reliable; use by default |
| Square / Tight | Text wraps around | Magazine-style layouts |
| Behind / In Front | Floats over text | Watermarks, overlays |

Floating images are the cause of most documents that "jump around" when edited.
Use In Line with Text unless you have a reason not to.

## Lesson 4.3 — Captions and cross-references

Insert → Caption adds a numbered caption. Insert → Cross-reference refers to it by
number, and updates if the figure moves. This is how professional documents keep
their numbering correct.

::: exercise
**Exercise 4.3 — A table and a figure**

1. Build a five-column table with a repeated header row.
2. Add an image, set to In Line with Text, with a caption.
3. Add a cross-reference to the table elsewhere in the text.
4. Add three rows to the table. Does everything still look right?

**Time:** 35 minutes. **Deliverable:** a document with a proper table and figure.
:::

# Module 5 — Mail Merge

## Lesson 5.1 — What mail merge does

It takes one document and one list, and produces many personalised documents:
letters, certificates, labels, envelopes, emails.

## Lesson 5.2 — The three-step method

1. **Prepare the data** in Excel: one row per recipient, one column per field.
   Column headers must be single words with no spaces: `FirstName`, `Amount`,
   `Date`.
2. **Prepare the template** in Word, with placeholders written as plain text:
   `«FirstName»`.
3. **Connect them**: Mailings → Start Mail Merge → Letters → Select Recipients →
   Use an Existing List. Then Insert Merge Field for each placeholder.

## Lesson 5.3 — Preview and finish

Preview Results shows the first record. Check three records, not one — errors hide
in records two and three. Then Finish & Merge → Edit Individual Documents, so you
can check before printing.

## Lesson 5.4 — The certificate use case

The most valuable mail merge in a school or training institution: 200 certificates,
each with a name, a course and a date, from one template and one spreadsheet.

::: exercise
**Exercise 5.4 — Merge 20 letters**

1. Build an Excel sheet with 20 rows: Name, Amount, DueDate.
2. Build a Word letter with three merge fields.
3. Connect and preview.
4. Check three records for errors.
5. Merge to a new document and save it.

**Time:** 45 minutes. **Deliverable:** 20 personalised letters.
:::

# Module 6 — Long Documents

## Lesson 6.1 — The table of contents

References → Table of Contents → Automatic. It builds from your heading styles.
If it is empty, your headings are not styled — go back to Module 2.

Update it before printing. An out-of-date table of contents is worse than none.

## Lesson 6.2 — Numbering that does not break

Use the multilevel list linked to heading styles. Then Heading 1 becomes "1.",
Heading 2 becomes "1.1.", and so on — automatically, and correctly, even after you
insert a new section.

Manually typed numbers always break. This is the fix.

## Lesson 6.3 — Track changes and comments

Review → Track Changes records every edit. Comments let reviewers ask questions
without changing the text.

The professional habit: send documents with track changes on, and resolve every
comment before the final version.

## Lesson 6.4 — Find and replace with wildcards

Beyond simple replacement: replace double spaces with single, remove manual line
breaks, standardise quotation marks. Small operations that save hours on long
documents.

::: exercise
**Exercise 6.4 — Build a report**

1. Create a ten-page document with at least eight headings.
2. Apply multilevel numbering linked to the heading styles.
3. Insert an automatic table of contents.
4. Add page numbers in the footer.
5. Update the table of contents and check every page number is correct.

**Time:** 60 minutes. **Deliverable:** a report that would not embarrass you.
:::

# Module 7 — Printing and Sharing

## Lesson 7.1 — Print preview is not optional

Check: page count, orphan headings at page bottoms, tables split badly, images cut
off, margins.

## Lesson 7.2 — Export to PDF

File → Save As → PDF. Choose "Standard" for sharing, "Minimum size" for email.

PDF preserves the layout on any device. A Word document opened on a different
computer can shift. For anything a client will see, send a PDF.

## Lesson 7.3 — Protecting a document

Review → Restrict Editing, or File → Info → Protect Document → Mark as Final.

Neither is real security — anyone determined can remove them. For real protection,
use a password on the PDF.

::: exercise
**Exercise 7.3 — Export and inspect**

1. Export your report to PDF.
2. Open the PDF and check every page.
3. Send it to yourself by email and open it on your phone.
4. Is it readable at phone size? If not, increase the body font size.

**Time:** 20 minutes. **Deliverable:** a PDF you have actually checked.
:::

# Module 8 — Using AI Inside Word

## Lesson 8.1 — What Copilot does well

Drafting from a prompt, rewriting a paragraph at a different reading level,
summarising a long document, generating a table from text, and suggesting
structure.

## Lesson 8.2 — What it does badly

Producing a document with your voice, knowing your organisation's conventions,
and getting numbers right. It drafts; you decide.

## Lesson 8.3 — The practical workflow

1. Write the outline yourself, in headings.
2. Ask AI to draft under each heading, with a specific brief.
3. Rewrite every paragraph in your own words — this is not optional.
4. Check every fact and figure.
5. Format with styles, not by hand.

::: warn
**Never paste a client's confidential document into a public AI tool.** Remove
names, ID numbers and financial details first, or use an approved enterprise tool.
:::

::: exercise
**Exercise 8.3 — Draft with AI, finish by hand**

1. Write a five-heading outline for a real document.
2. Ask AI to draft each section, 150 words each, in a specified tone.
3. Rewrite every section in your own words.
4. Apply styles and formatting.
5. Compare the result to what you would have written alone. Time both.

**Time:** 45 minutes. **Deliverable:** a document and a time comparison.
:::

# Module 9 — Capstone

## Lesson 9.1 — The brief

Produce one document containing: a cover page, a styled table of contents, at
least three heading levels with automatic numbering, a table with a repeated
header, an image with a caption, a header and footer with page numbers, and a
final PDF export.

## Lesson 9.2 — The rubric

| Criterion | Weight | Excellent | Weak |
|---|---|---|---|
| Styles | 30% | Consistent, modified deliberately | Manual formatting |
| Navigation | 20% | Working TOC, correct numbering | Typed numbers, stale TOC |
| Layout | 20% | Clean margins, no orphans, correct breaks | Cramped, broken tables |
| Tables & figures | 15% | Headers repeat, captions cross-referenced | Manual, misaligned |
| Export | 15% | PDF checked on two devices | Word file only |
