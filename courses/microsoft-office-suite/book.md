# Module 1 — The Suite as One System

Most people learn Word, then Excel, then PowerPoint, as three unrelated skills.
They are not. They are one system for turning information into decisions and
decisions into communication.

This course teaches all five tools to working competence, and then — the part
nobody teaches — how to make them work together.

::: scripture
"For the body is not one member but many… but now indeed there are many members,
yet one body."
— 1 Corinthians 12:14, 20
:::

Five tools, one body of work. Each is limited alone. Together they do what a
business needs.

## Lesson 1.1 — What each tool is for

| Tool | Core job | Wrong job |
|---|---|---|
| **Word** | Language: letters, reports, policies | Calculation |
| **Excel** | Numbers: totals, analysis, charts | Long prose |
| **PowerPoint** | Persuasion: a spoken argument | Reading material |
| **Access** | Relationships: structured records | Quick lists |
| **Outlook** | Coordination: mail, calendar, contacts | File storage |

## Lesson 1.2 — The integration map

```
Excel data  ──link──▶  Word report
Excel data  ──link──▶  PowerPoint chart
Excel list  ──merge─▶  Word letters/certificates
Access query ─export─▶ Excel analysis
Outlook     ──attach─▶ any of the above
```

Learn those five arrows and you have the whole course.

## Lesson 1.3 — The capstone you are building toward

A complete business report package: data collected and stored, analysed,
written, presented, and circulated — all five tools, one workflow.

::: exercise
**Exercise 1.3 — Map your own work**

1. List five documents you produce regularly.
2. For each, note which tools it currently uses.
3. Mark where you do something manually that could be linked or automated.
4. Choose the one that wastes the most time. That is your capstone.

**Time:** 25 minutes. **Deliverable:** a list of five, with one chosen.
:::

# Module 2 — Word to Working Competence

## Lesson 2.1 — Styles first

Heading 1, Heading 2, Normal. Apply them. Never format headings by hand.

Everything that follows — table of contents, navigation, numbering — depends on
this one habit.

## Lesson 2.2 — The professional document

- One or two fonts, sizes 11–12 for body.
- 2.5 cm margins.
- Left-aligned, not justified.
- Consistent spacing set in the style, not by pressing Enter.
- Page numbers in the footer.
- A cover page with "Different First Page" enabled.

## Lesson 2.3 — Tables, images and captions

Tables: set widths by dragging borders, repeat header rows, prevent rows splitting
across pages.

Images: use "In Line with Text" unless you have a reason not to. Floating images
cause layout chaos.

Captions: Insert → Caption, then cross-reference so numbering updates itself.

## Lesson 2.4 — Mail merge

Data in Excel, template in Word, connect with Mailings → Start Mail Merge. Preview
three records, never one.

::: exercise
**Exercise 2.4 — Word competency check**

Produce one document with: a cover page, a styled table of contents, three heading
levels with automatic numbering, a table with a repeated header, an image with a
caption, and page numbers.

**Time:** 60 minutes. **Deliverable:** the document, exported to PDF.
:::

# Module 3 — Excel to Working Competence

## Lesson 3.1 — The twenty formulas that cover most work

`SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MAX`, `MIN`, `ROUND`, `IF`, `IFS`, `AND`,
`OR`, `SUMIF`, `SUMIFS`, `COUNTIF`, `COUNTIFS`, `VLOOKUP`, `XLOOKUP`, `INDEX`,
`MATCH`, `TEXT`.

Learn these and you will rarely be stuck.

## Lesson 3.2 — Structure

One table per sheet. No merged cells in data. One value per cell. Header row with
single-word names. Convert the range to a Table (Ctrl+T) so formulas fill down
automatically.

## Lesson 3.3 — Analysis

Pivot tables for grouping. Charts for communication. Conditional formatting for
attention.

## Lesson 3.4 — The monthly report that builds itself

Raw data sheet → pivot table → dashboard sheet. Each month: paste new data,
refresh, done.

::: exercise
**Exercise 3.4 — Excel competency check**

Build a workbook with: a clean data table, six formulas including SUMIFS and a
lookup, a pivot table, two charts, and conditional formatting that highlights
unpaid rows.

**Time:** 60 minutes. **Deliverable:** the workbook.
:::

# Module 4 — PowerPoint to Working Competence

## Lesson 4.1 — The master

Set fonts, colours, logo and footer once in the Slide Master. Every slide inherits
them.

## Lesson 4.2 — Restraint

Six bullets maximum, six words each. Titles that state the finding. Generous white
space. One image that earns its place.

## Lesson 4.3 — Charts in slides

Copy from Excel with Paste Special → Link, so the chart updates. Then simplify:
delete gridlines, add data labels, grey out everything except the point you are
making.

## Lesson 4.4 — Delivery

Presenter View. Rehearse with timing. Notes as prompts, not scripts.

::: exercise
**Exercise 4.4 — PowerPoint competency check**

Build a ten-slide deck on your own master with a linked Excel chart, rehearsed to
five minutes, exported to PDF and as a three-per-page handout.

**Time:** 60 minutes. **Deliverable:** the deck in three formats.
:::

# Module 5 — Access to Working Competence

## Lesson 5.1 — When to use it

When relationships matter, when more than one person enters data, when Excel has
started to break.

## Lesson 5.2 — The minimum viable database

Three tables, related, with referential integrity. Two forms. Three queries
including a totals query. Two reports. A navigation form.

## Lesson 5.3 — The rules

AutoNumber primary keys. Correct field types. One value per cell. No repeated
groups. Back up daily. Never on a synchronised cloud folder.

::: exercise
**Exercise 5.3 — Access competency check**

Build a three-table database with one relationship enforced, one form with a
subform, one totals query, and one printable report.

**Time:** 75 minutes. **Deliverable:** a working database.
:::

# Module 6 — Outlook to Working Competence

## Lesson 6.1 — Email that gets answered

Short. Specific subject. One ask. Clear close. Attachment named usefully.

## Lesson 6.2 — Folders and rules

Create folders by project or client. Set rules to move incoming mail automatically.
An inbox with 400 unread messages is not a working system.

## Lesson 6.3 — Calendar discipline

Every commitment in the calendar, with a reminder. Time-blocked work for anything
that needs concentration. A shared calendar for anything a colleague needs to know.

## Lesson 6.4 — Contacts and groups

Store contacts properly. Create distribution lists for the groups you email
regularly.

::: exercise
**Exercise 6.4 — Outlook competency check**

Set up three folders, one automatic rule, one distribution list, and put next
week's commitments in the calendar with reminders.

**Time:** 40 minutes. **Deliverable:** an organised mailbox and calendar.
:::

# Module 7 — Integration: Where the Value Is

## Lesson 7.1 — Excel to Word

Paste Special → Paste Link. The Word table updates when the spreadsheet changes.
Format in Excel, not Word, because Word's changes are overwritten.

## Lesson 7.2 — Excel to PowerPoint

Paste Special → Paste Link for charts. The slide updates when the data changes —
essential for a monthly board pack.

## Lesson 7.3 — Excel to Word mail merge

One spreadsheet, one template, hundreds of personalised documents. Certificates,
invoices, letters, statements.

## Lesson 7.4 — Access to Excel

External Data → Export → Excel. Take the query result into Excel for pivot
analysis, or into Word for a report.

## Lesson 7.5 — The complete workflow

1. Data entered into Access (or Excel, for small volumes).
2. Query or pivot produces the analysis.
3. Chart created in Excel.
4. Report written in Word with linked table and chart.
5. Presentation built in PowerPoint with linked chart.
6. Everything distributed by Outlook.

That is a monthly board pack, and it takes an hour instead of a day.

::: exercise
**Exercise 7.5 — Build one complete workflow**

1. Take real data.
2. Produce the analysis in Excel.
3. Write a two-page report in Word with a linked table and chart.
4. Build a five-slide summary with the linked chart.
5. Email the PDF and the deck to one person.

**Time:** 90 minutes. **Deliverable:** a complete package.
:::

# Module 8 — AI Across the Suite

## Lesson 8.1 — Where it helps in each tool

| Tool | Useful AI use |
|---|---|
| Word | Draft, rewrite, summarise, suggest structure |
| Excel | Write formulas, explain formulas, suggest charts |
| PowerPoint | Speaker notes, cut bullets, suggest structure |
| Access | Explain a query, suggest table design |
| Outlook | Draft replies, summarise threads |

## Lesson 8.2 — The rule that applies everywhere

**AI drafts; the human verifies.** Especially numbers. A wrong total in a report
presented to a board is not a small error.

## Lesson 8.3 — The safe pattern

Describe precisely, get the output, test on known examples, then use. Never paste
confidential data into a public tool.

::: exercise
**Exercise 8.3 — One AI workflow per tool**

1. Word: draft a paragraph, rewrite it in your own voice.
2. Excel: get a formula, test it on three rows.
3. PowerPoint: generate speaker notes, cut them to 40 words.
4. Outlook: draft a reply to a real email, edit before sending.
5. Note the time saved for each.

**Time:** 45 minutes. **Deliverable:** four AI-assisted outputs and a time log.
:::

# Module 9 — Capstone: The Complete Package

## Lesson 9.1 — The brief

Produce a complete business package for a real or realistic organisation:

1. A database or clean spreadsheet holding the data.
2. An analysis with a pivot table and a chart.
3. A written report with linked data and an automatic table of contents.
4. A presentation of the findings with a linked chart.
5. A mail merge producing ten personalised documents.
6. Everything distributed by email, as PDF.

## Lesson 9.2 — The rubric

| Criterion | Weight | Excellent | Weak |
|---|---|---|---|
| Data foundation | 20% | Clean, structured, correct types | Messy, duplicated |
| Analysis | 20% | Pivot answers a real question, chart communicates | Numbers without meaning |
| Documents | 20% | Styled, linked, print-ready | Manually formatted |
| Presentation | 15% | Clear, restrained, rehearsed | Crowded, read aloud |
| Integration | 15% | Links work and update | Static copy-paste |
| Professional finish | 10% | PDFs checked on two devices | Untested files |
